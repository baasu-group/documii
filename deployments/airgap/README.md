# Air-gapped deployment contract

Air-gapped releases will provide prebuilt application/container artifacts, checksums, a software bill of materials, and a list of optional model artifacts obtained under their own licenses. At runtime set `AIR_GAPPED=true`; bundle assets and fonts locally; disable telemetry, remote update checks, automatic model downloads, and providers/connectors requiring unreachable endpoints. Operators mirror images and dependencies through their approved transfer process.
